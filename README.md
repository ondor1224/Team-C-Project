# c조 게임 개발 프로젝트
## 1. 게임 개요

- 게임 타이틀: 미정
- 게임 장르: 로그라이크, 수집형 RPG, 랜덤 디펜스
- 게임 시점: 쿼터뷰
- 게임 플랫폼: PC
- 게임 설명: 뽑기에서 드래곤 캐릭터 15명을 얻을 수 있다. 모은 캐릭터 중 10명을 전장에 보내 적과 싸운다. 총 25개 스테이지가 있고, 적을 처치해 얻은 재화로 캐릭터를 키우거나 스킬을 구매한다.
- 게임 목표: 모든 스테이지를 클리어하고 엔딩까지 가는 것이다. 재화를 모아 캐릭터를 뽑고 키워서 다음 스테이지에 도전한다.

## 2. 게임 시스템 디자인

- 게임 진행 방식: 캐릭터를 전장에 소환해 적을 막는다. 일반 스테이지 4개를 지나면 보스가 나오고, 보스를 처치하면 다음 테마로 넘어간다.
- 게임 룰: 스테이지는 정해진 시간이 지나면 클리어된다. 캐릭터를 소환할 때 주사위를 굴리며, 숫자가 높을수록 캐릭터의 기본 능력치가 높아진다. 처음에는 코스트 에너지 10칸으로 시작하고, 캐릭터마다 소환에 필요한 코스트가 다르다. 코스트는 캐릭터 소환과 스킬 사용에 모두 필요하다. 스테이지를 클리어하면 강화할 수 있고, 상점에서는 스킬을 살 수 있다.
- 게임 인터페이스: 타이틀 화면(시작, 설정, 종료), 준비 화면(상점, 뽑기, 전장 구성, 보유 코인, 캐릭터 강화), 플레이 화면(주사위, 소환 칸 3개, 코스트 게이지, 적과 캐릭터 체력, 점수, 스테이지), 클리어 화면(클리어한 스테이지 수, 점수)

## 3. 캐릭터 및 스토리

- 주요 캐릭터 소개: 주인공은 여신에게 선택받은 드래곤 테이머다. 뽑기에서 나오는 캐릭터는 총 15명이고, 모두 드래곤이다.
- 스토리: 마왕이 지구를 침략해 세계가 혼란에 빠진다. 주인공은 왕궁의 부탁을 받고 드래곤들과 함께 마왕과 마왕군을 물리치러 간다.

## 4. 레벨 디자인 설계

- 스테이지별 레벨 목록: 일반 스테이지 4개와 보스 스테이지 1개를 5개 테마에서 반복한다. 총 25개 스테이지다.
    - 1테마: 마을 2개 → 왕국 2개 → 보스
    - 2테마: 초원 2개 → 드래곤계 입구 2개 → 보스
    - 3테마: 물 지역 2개 → 불 지역 2개 → 보스
    - 4테마: 얼음 지역 2개 → 번개 지역 2개 → 보스
    - 5테마: 마계 2개 → 마왕성 2개 → 보스
- 각 레벨의 목적과 특징: 테마마다 보스가 나오며, 총 5명의 보스가 등장한다. 보스는 오크왕, 짐승왕, 골렘왕, 사령왕, 마왕이다. 1~2테마에는 적 3종류, 3~5테마에는 적 4종류가 나온다. 적은 테마에 따라 모습은 달라지지만 움직이는 방식은 같다. 예를 들어 고블린과 늑대는 모두 부딪쳐 공격한다.
